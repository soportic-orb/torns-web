# Mailing images

Images used by Mailing campaigns (panel.torns.app › Mailing), served at
`https://www.torns.app/themes/torns/images/mailing/<campaign>/<file>`.
One folder per campaign; files are never renamed or deleted once a campaign
has been sent, because sent emails keep linking to them.

- `2026-12-agenda/` — home screen setting and agenda events, in es/ca/gl/eu:
  `torns-mail-hero-<lang>.jpg` (calendar and day sheet),
  `torns-mail-profile-<lang>.jpg` (Perfil › Pantalla principal),
  `torns-mail-widget-<lang>.jpg` (widget «Turnos y agenda»).
  Example data only: no real user, centre schedule or event.
